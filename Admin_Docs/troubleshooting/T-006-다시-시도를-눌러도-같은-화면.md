# T-006 "다시 시도"를 눌러도 같은 화면이 나옴

## 한눈에 보기 (코드 몰라도 OK)
무슨 문제였나: 화면의 "다시 시도" 버튼이 화면을 새로 불러오긴 하는데, 서버가 1분 동안 기억해 둔 결과를 그대로 다시 보여 줬다. 눌러도 최대 1분은 달라지지 않았다.
어떻게 해결했나: 버튼을 누르면 서버가 기억해 둔 혼잡도 결과를 먼저 지우고, 그다음에 화면을 다시 불러오게 했다.

## 개발자 상세
- 증상(리뷰 R3이 Next 내장 문서로 확인): `router.refresh()`는 서버의 `"use cache"` 결과를 무효화하지 않는다.
- 원인: 페이지를 미리 만들어 두려고 데이터 함수를 1분 캐시했는데(D-006), 버튼은 그 캐시를 건드리지 못했다.
- 해결: `frontend/src/lib/data.ts`의 두 함수에 `cacheTag("crowd")`. `frontend/src/app/actions.ts`의 서버 동작 `refreshCrowdData()`가 `updateTag("crowd")`로 캐시를 비운다. `RetryButton`은 이 동작을 부른 뒤 `router.refresh()`.
- 주의한 점: 누구나 부를 수 있는 동작이라, 연달아 눌러 캐시를 계속 비우지 못하게 5초 간격을 두었다(서버 프로세스 메모리의 시각으로 판단).
- 확인: 백엔드를 껐다 켜는 실행 확인은 했다(끄면 "불러오지 못했어요", 켜면 회복). 버튼을 브라우저에서 직접 누르는 확인은 아직 못 했다(STATUS 참고).
- 관련: F-003 (1차 리뷰 R3 [주의]), D-006
