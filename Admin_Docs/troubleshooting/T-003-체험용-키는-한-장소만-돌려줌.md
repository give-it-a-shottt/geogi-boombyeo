# T-003 체험용 키는 어떤 장소를 물어도 한 장소만 돌려줌

## 한눈에 보기 (코드 몰라도 OK)
무슨 문제였나: 서울시의 체험용 인증키(sample)로 121곳을 물어봤더니, 전부 "광화문·덕수궁"의 값이 돌아왔다. 오류 없이 정상 응답으로 오기 때문에 그대로 저장하면 121곳이 모두 같은 값이 된다.
어떻게 해결했나: 응답에 적힌 장소 코드가 물어본 장소와 같은지 확인하고, 다르면 그 장소는 수집 실패로 기록한다.

## 개발자 상세
- 증상: 체험용 키로 `citydata_ppltn/1/5/POI050`을 부르면 응답의 `AREA_CD`가 `POI009`. 없는 코드(POI999)를 넣어도 같은 응답.
- 원인: 체험용 키의 동작(한 장소 고정). 문서에는 나와 있지 않아 직접 호출해 보고 알았다.
- 해결: `parse_response(data, expected_code)`에서 `AREA_CD` 대조(D-009). 체험용 키로 한 바퀴 돌리면 "성공 1, 실패 120(요청한 장소와 다른 장소의 응답)"이 나온다.
- 확인: 실제 인증키로는 121곳 전부 성공(2026-11-23, 한 바퀴 2.3초).
- 재발 방지: `test_parse_rejects_other_place`, `test_collect_once_one_place_failing_does_not_stop_others`
- 관련: F-001, D-009
