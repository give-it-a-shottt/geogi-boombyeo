# D-005 장소 좌표는 영역의 무게중심, 거리는 직접 계산

## 한눈에 보기 (코드 몰라도 OK)
상태: [통과]

무엇을: 서울시 API는 장소의 좌표를 주지 않는다. 서울시가 함께 공개한 "121장소 영역" 파일에서 각 영역의 한가운데 점을 구해 장소 좌표로 쓴다. 두 곳 사이 거리는 지도 API를 부르지 않고 공식으로 직접 계산한다.
왜: "근처 덜 붐비는 곳"에는 장소끼리의 거리가 필요하다. 121곳뿐이라 직접 계산해도 충분히 빠르고, 지도 API 호출이 0번이라 비용과 한도 걱정이 없다.

## 개발자 상세

- 좌표: `backend/scripts/build_seed.py`가 shapefile(WGS84)의 다각형마다 넓이 가중 무게중심을 구해 `app/seed/places.json`에 넣는다.
- 거리: `app/services/geo.py`의 하버사인 공식(직선 거리). 요청마다 최대 121번 계산.
- 길찾기 버튼은 네이버 지도 웹 검색 주소(장소 이름)로 연결한다. 지도 SDK · 키를 쓰지 않는다.

제약: 직선 거리라 실제 걷는 거리와 다르다. 한강공원처럼 긴 영역은 무게중심이 입구와 멀 수 있다.
바꿔야 하는 조건: 지도 화면(2차 후보)을 넣거나 실제 이동 시간이 필요해지면 네이버 클라우드 Maps를 붙인다.
