# D-009 응답의 장소 코드를 요청한 장소와 대조

## 한눈에 보기 (코드 몰라도 OK)
상태: [통과]

무엇을: 서울시 API에서 받은 응답이 정말 우리가 물어본 장소의 것인지, 응답 안의 장소 코드를 확인한 뒤에만 저장한다. 다르면 그 장소는 "수집 실패"로 적는다.
왜: 체험용 인증키(sample)는 어떤 장소를 물어도 광화문·덕수궁 한 곳의 값만 돌려준다. 확인 없이 저장하면 121곳이 전부 같은 값이 되는데, 겉으로는 정상처럼 보인다.

## 개발자 상세

- `parse_response(data, expected_code)`가 `AREA_CD != expected_code`이면 `SeoulApiError("요청한 장소와 다른 장소의 응답")`.
- 요청은 장소 이름(AREA_NM)으로 하고, 대조는 장소 코드로 한다. 이름으로 요청하는 방식은 서울시 매뉴얼의 예시와 같고 실제 인증키로 121곳 전부 확인했다(2026-11-23).
- 인증키 오류는 상태 200에 XML 본문으로 온다 → JSON 해석 실패 시 XML의 `<CODE>`를 꺼내 사유로 남긴다.

발견 경위: 체험용 키로 수집을 돌렸더니 성공 1 · 실패 120이 나왔다(T-003).
제약: 서울시가 장소 코드 체계를 바꾸면 전부 실패로 기록된다. 그때는 시드를 새로 만든다.
