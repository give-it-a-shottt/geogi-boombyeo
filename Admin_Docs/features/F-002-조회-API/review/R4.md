(3) `/api/nearby`의 `base` 카드에도 `distance_km`가 채워진다. — `backend/app/services/places.py` `alternatives`, `nearby_from_location` — 확인한 범위: places.py, api-list.md, OPEN_QUESTIONS.md — 고치는 방법: api-list.md "규칙"에 한 줄씩 적는다. (1)은 Q 항목 추가를 제안한다.
- [제안] [확실] 한 번도 수집되지 않은 장소의 상세는 `timeline: []`을 돌려주는데 api-list는 "예측이 없으면 1개"로만 적었다. — `backend/app/services/places.py` `detail` — 확인한 범위: places.py, api-list.md, types.ts — 고치는 방법: api-list의 timeline 행에 "수집된 적 없으면 빈 목록"을 적는다.
