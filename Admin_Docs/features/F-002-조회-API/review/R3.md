## 체크 항목별 근거
- 프론트 항목 → 해당 없음 (백엔드 기능)
- 404 → `place_detail`·`nearby_from_place`, 테스트 있음 → 이상 없음
- 422 → 좌표 범위, 분류, `q` 길이 모두 처리하고 테스트 있음. 공백만 있는 `q`는 지적 1
- 400/401/403/409 → 해당 없음 (읽기 전용, 인증·중복 개념 없음)
- 500 경로(빈 데이터) → `load_views`·`home`·`detail`·`nearby_*`가 수집 전, `level` NULL, 지연, 예측 없음을 분기로 처리. 예외 경로 없음. `level=NULL` 행의 테스트는 지적 2
- 트랜잭션·DB 제약 → 해당 없음 (쓰기 없음)
- 외부 API 실패 → 해당 없음 (조회는 DB만 봄)
- `build_answer` 경계 → 단계 혼합, 자정 조사, 내일 접두어는 정상. 예측 1개·끝 시각 자정/다음 날 테스트 없음(지적 3)
- 테스트 존재·균형 → 정상·404·422·빈 상태는 다룸. 상한·경계·지연 근처 제외는 지적 2

- 완료 기준 3 → 5km·거리순·0곳은 있음, 3곳 상한·여유 기준 없음
