## 지적
- [주의] [확실] /api/docs(Swagger UI)와 /api/openapi.json이 인터넷에 공개된다. D-007의 중계가 /api/ 아래 GET을 전부 백엔드로 넘기고, 경로 검사가 "docs"와 "openapi.json"을 막지 않으며 content-type도 그대로 넘긴다. 데이터가 공개 정보라 [위험]으로는 보지 않았다. — backend/app/main.py `FastAPI(docs_url=..., openapi_url=...)` — 확인한 범위: main.py, compose, route.ts, lib/backend.ts, D-007 — 고치는 방법: 설정으로 운영에서는 문서 주소를 끄거나, 중계에 허용 경로 목록을 둔다.
- [제안] [추정] 같은 이유로 7개 GET도 사실상 공개인데, 요청마다 세 표를 전부 읽고 중계는 no-store이며 요청 수 제한이 없다. 확인하면 확실해지는 것: /api/search와 /api/nearby를 동시에 여러 개 보내 응답 시간과 DB 연결 수를 잰다. — app/api.py `_views`, app/services/places.py `load_views` — 확인한 범위: api.py, places.py, route.ts — 고치는 방법: `load_views` 결과를 30~60초 메모리에 캐시하거나 앞단에 요청 수 제한을 둔다.
- [제안] [추정] lat·lng에 "nan"을 넣으면 422가 아니라 200(base 없음)이 나올 수 있다. 확인하면 확실해지는 것: `/api/nearby?lat=nan&lng=nan`의 상태 코드. — app/api.py `Latitude`, `Longitude` — 확인한 범위: api.py, geo.py, places.py, test_api.py — 고치는 방법: `Query(..., allow_inf_nan=False)`로 막는다.
