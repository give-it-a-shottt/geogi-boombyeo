## 한눈에 보기
상태: [됨] — 1차 리뷰 [보완], 지적 반영 끝
무엇을: DB에 모아 둔 값을 화면이 바로 쓸 모양으로 돌려준다. "언제 가면 되는지" 답 한 줄, 여유 순위(TOP 5), 근처 덜 붐비는 곳, 장소 검색.
왜: 서비스가 하려는 일은 정보를 펼쳐 놓는 것이 아니라 판단을 대신해 주는 것이다. 그 판단(문장 · 순위 · 대안)을 한 곳에서 계산해 모든 화면이 같은 답을 보게 한다.

## 설계 의도 (AI 대리 작성 — 사용자 위임, 2026-11-23)
- 이 기능이 해결하는 문제: 공식 사이트는 숫자와 단계만 보여 주고 "그래서 언제 가라는 건지"는 사용자가 판단해야 한다.
- 완료 기준:
  1. 답 한 줄이 디자인 md의 문구 규칙 표와 같다(구간형, 그나마 덜 붐빔, 계속 같은 단계, 예측 없음, 내일).
  2. TOP 5는 지금 단계가 낮은 순 → 여유가 오래 이어지는 순이고, 지연된 장소는 빠진다. 둘 다 같으면 지금 사람이 적은 곳이 먼저다. (사용자 확인, 2026-11-23 — 배포 뒤 저녁에 다섯 곳이 모두 "계속 여유"라 순위가 이름순이 되는 것을 보고 추가)
  3. 근처 대안은 5km 안에서 더 덜 붐비는 곳을 가까운 순으로 3곳까지, 0곳이면 빈 목록을 돌려준다.
  4. 내 위치 기준 요청은 5km 안에 장소가 없으면 기준 장소 없이 응답한다.
  5. 검색은 공식 이름과 별칭("홍대", "ddp")으로 찾고, 결과가 없으면 비슷한 장소 3곳을 제안한다.
  6. 없는 장소는 404, 잘못된 입력은 422. (리뷰 뒤 넓힘: 띄어쓰기 · 기호만 있는 검색어, nan 좌표도 422)
  7. 관측 시각이 60분보다 오래된 장소는 지연으로 표시하고 그 예측은 쓰지 않는다.
- 화면: 없음 (F-003이 사용)
- API: overview/api-list.md의 7개 (전부 GET)
- 데이터: places · place_status · forecasts 읽기만
