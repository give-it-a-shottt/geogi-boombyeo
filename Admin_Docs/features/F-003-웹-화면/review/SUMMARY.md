- 수용할 지적과 이유: [주의] 5건 전부와 [제안] 6건. "다시 시도"가 실제로는 기다려야 풀리는 것, sitemap 주소가 localhost로 굳는 것은 완료 기준과 서비스 목적(검색엔진 유입)에 직접 걸려서 고쳤다. 중계 허용 목록 · 보안 헤더 · server-only는 고치는 비용이 작고 나중의 실수를 막아 줘서 넣었다.
- 거절할 지적과 이유: 없음. 미반영 5건은 틀린 지적이 아니라 지금 고칠 만큼 급하지 않은 정리다.
- 다음에 고칠 것: (1) 반복되는 문구를 상수로 모으기. (2) "지금 + 미터 + 배지" 묶음과 예측 없음 안내를 작은 컴포넌트로 빼서 CSS가 새지 않게 하기. (3) 최근 검색을 훅으로 분리. (4) 그래프 막대 높이를 CSS 변수 한 곳에서 정하기. (5) `/api/places`에 짧은 캐시 — 배포 후 사용량을 보고.
