## 지적
- [신규] [주의] [확실] 저장 실패 테스트가 롤백을 검증하지 못한다. 가짜 저장 함수가 session을 건드리기 전에 예외를 던지고, 단언한 Snapshot 120건은 롤백이 없어도 성립한다. `record_failure`까지 실패하는 분기에도 테스트가 없다. — backend/tests/test_collector_failures.py `test_save_failure_is_recorded_for_that_place_only` — 확인한 범위: 해당 테스트와 `service._save` 전체 — 고치는 방법: 반쯤 쓴 뒤 실패하게 바꾸고, 실패한 장소의 Snapshot·Forecast·level이 하나도 남지 않았는지 단언한다. 실패 기록도 못 남기는 경우를 추가한다.
- [신규] [주의] [추정] `_save`가 `SQLAlchemyError`만 잡는다. 저장 단계에서 그 밖의 예외가 나면 `collect_once`가 중간에 죽어 뒤쪽 장소는 가져온 값도 저장하지 못한다. 확인하면 확실해지는 것: `store_observation` 안에서 SQLAlchemy가 감싸지 않는 예외가 나올 수 있는지. — backend/app/collector/service.py `_save` — 확인한 범위: service.py, client.py, seed.py (models.py는 열지 않음) — 고치는 방법: `except Exception`으로 넓히고 같은 경로로 처리한다.
- [신규] [제안] [확실] `_to_int`가 `OverflowError`를 못 잡는다(`"1e999"`). `parse_seoul_time`에서 연도가 범위를 벗어나는 값도 같은 경우. 한 바퀴는 멈추지 않지만 `parse_response`의 약속과 어긋나고 테스트에도 없다. — backend/app/collector/client.py `_to_int`, `parse_response` — 확인한 범위: client.py, timeutil.parse_seoul_time — 고치는 방법: except에 OverflowError를 추가하고 테스트에 넣는다.
- [신규] [제안] [확실] 예상 못 한 예외는 DB에 종류 이름만 남고 로그에는 아무것도 안 남아 원인 추적이 어렵다(traceback을 안 찍은 것은 맞는 선택). — backend/app/collector/service.py `_fetch_all.fetch` — 확인한 범위: service.py — 고치는 방법: 장소 코드와 예외 종류 이름만 경고 로그로 남긴다.

## 체크 항목별 근거
- 프론트 항목 → 해당 없음
- 우리 쪽 API 응답 코드 → 해당 없음 (서울시 API 상태는 4xx 즉시 실패, 5xx 재시도로 처리함)
- 외부 API 실패 대응 → `fetch_place`·`parse_response`·`_decode`, `_fetch_all` → 시간 초과·연결 실패·5xx·4xx·XML 인증 오류·이상한 모양이 모두 장소별 SeoulApiError로 바뀜. OverflowError만 제안
- 한 바퀴 전체가 멈추지 않는가 → 가져오기 단계는 막혀 있음. 저장 단계는 지적 2. 한 바퀴가 통째로 실패해도 worker.run이 잡아서 계속 돎
- 트랜잭션 롤백 → `store_observation`(장소당 단일 commit), `_save`(rollback 뒤 기록) → 코드는 맞음. 테스트가 검증하지 못함(지적 1)
- DB 제약 위반(중복) → 사전 조회로 막고, 동시 삽입의 IntegrityError는 저장 실패로 기록됨. models.py의 제약 자체는 미확인
- 테스트 존재 → test_collector.py 11개, test_collector_failures.py 19케이스 → 정상·실패 경로 모두 있음
- 테스트 통과 → 패킷 결과(95 passed)를 근거로 함
- 완료 기준 1 ~ 6 → 각각 테스트 있음. 기준 2와 4는 함수를 직접 호출하는 테스트라 충분함. 기준 5는 로그·repr·DB를 모두 단언함
- 헛도는 단언 → 롤백 건 외에는 못 찾음

확인한 범위: 지정된 파일 전부(client.py, service.py, worker.py, seed.py, config.py, timeutil.py, 테스트 3개).
