# R3 예외 처리·테스트

- 프론트: 로딩·에러·빈 데이터 상태를 코드에서 처리하는가(화면 모양은 보지 않음), 네트워크 실패, 입력 오류 메시지
- 백엔드: 상황별 응답 코드(400/401/403/404/409/422/500), 트랜잭션 롤백, DB 제약 위반(중복 등)을 사용자 메시지로 바꾸는가, 외부 API 실패 대응
- 테스트: 이 기능의 테스트가 있는가, 정상·예외 경우를 둘 다 다루는가, 통과하는가 (리뷰 패킷의 테스트 결과를 근거로 남김, 패킷에 결과가 없을 때만 직접 실행)

지적마다 [확실]/[추정]과 확인한 범위를 붙인다. 디자인(색·간격·폰트·모양·접근성·색 대비)은 지적하지 않는다.
